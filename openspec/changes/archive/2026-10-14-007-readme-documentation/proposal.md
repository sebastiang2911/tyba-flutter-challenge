# Proposal

## Why

The repository still ships the default `flutter create` README. Evaluators grade engineering quality first, so the architecture, the decisions behind it and the steps to run the app must be documented before delivery.

## What Changes

- Replace the boilerplate `README.md` with project documentation: overview, features, how to run/test, architecture (layers, MVVM, DI, navigation), key decisions and trade-offs, testing strategy, project structure.
- Mark the README item as done in `ROADMAP.md`.

## Capabilities

### New Capabilities

None. Documentation only, no behavior changes.

### Modified Capabilities

None. The change sets `skip_specs: true`.

## Impact

- `README.md` (rewritten), `ROADMAP.md` (item moved to Done).
- No code, dependency or test changes.
